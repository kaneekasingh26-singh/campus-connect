# Campus Connect 🎓

Campus Connect is a responsive student community platform designed to help students discover campus events, resources, and opportunities in one place.

## 🚀 Features

* 📅 Explore upcoming campus events
* 💻 Discover student opportunities
* 📚 Access useful student resources
* 🤝 Connect with the campus community
* 📱 Responsive design for mobile and desktop
* ⚡ Interactive event buttons using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## 🌐 Live Demo

The project is deployed using GitHub Pages.

## 🎯 Purpose

The goal of Campus Connect is to create a simple and user-friendly platform where students can discover campus activities and useful resources without having to search through multiple platforms.
